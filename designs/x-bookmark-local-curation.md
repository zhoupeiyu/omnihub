# X 收藏同步与电脑本地整理

更新于 2026-10-01。

## 目标与当前状态

网站服务器每两小时读取个人 X 收藏，保存原始内容。电脑每两小时领取新增内容的整理任务，使用本机模型生成中文说明、分类、评分和引用，再把结果传回网站。电脑关机时，服务器继续收集，整理任务留在队列中。

本轮已写入同步器、设备任务接口、本地脚本和 LaunchAgent 生成器。自动化测试使用隔离数据库和模拟接口，没有部署到生产，也没有启用真实 X 抓取。当前 Codex CLI 的无工具调用方式尚未验证，本地模型执行器因此保持禁用，脚本会在领取任务之前停止。这份文档描述代码合同及启用条件，不代表定时任务已运行。

## 数据怎样流转

```text
X 收藏
  → 网站两小时同步
  → 私有原文 + 新增记录标记
  → 等待电脑领取
  → 分类 → 中文整理和评分 → 引用核验 → 归组
  → 同组多来源综合 → 再次核验
  → 私有整理结果
  → 主人确认公开后，才供访客浏览
```

两小时轮询有等待时间。收藏可能接近两小时后才入库，再等到电脑下一轮运行；额度、网络、休眠和多阶段处理会延长时间。当前每轮最多领取 10 个模型阶段，默认每天最多 40 次、每小时最多 12 次领取。一次收藏通常需要多个阶段，这些数字不能理解成每天能整理 40 篇。

每次模型调用都带确定的请求键。成功阶段留在服务器，下次继续后续阶段。电脑回传失败时把结果放进权限为 0600 的本地 outbox，下一次优先重传。来源变化、人工改类、删除或设备被撤销后，旧结果不能写回。

## 保留规则

现有原文、人工分类、介绍、忽略状态和可见性均保留。抓到已存在的帖子时不覆盖这些字段，也不再次加入新增整理范围。网站没有收录的旧帖子仍可作为新增记录导入，不能用帖子发布时间代替收藏时间。

新原文以 `private`、`pending` 入库。自动整理只处理同步器登记的新增 ID，不启动历史全库重跑。同步返回不完整、游标重复、达到分页或费用上限时保留已经收到的原文，记录失败状态；不据此删除网站已有收藏。

这里的增量指入库和 AI 整理。X 收藏接口没有提供 `since_id`，当前文档也没有明确按收藏时间排序，不能承诺一次请求只读到新增收藏。代码保存分页游标，达到本轮上限后下次继续；到达接口返回的末页才结束这一轮扫描。分批扫描可能让新收藏晚于两小时入库，接口末页也不能证明取得了账号的全部历史收藏。

用户在网站删除过的 X 记录会留下不含正文的删除标记，后续抓取不再把它重新创建。抓取日志只保存分页元数据和帖子 ID，不另存每轮重复正文。

新的整理结果使用既有内容流程，必须通过中文字段、评分范围和原文引用校验。方法技巧、完整提示词、仓库、动态等仍分别判断，材料不足留待处理。自动整理不会替用户勾选公开，也不会把仓库介绍直接覆盖成模型摘要。

当前归组沿用 `content_groups`，可合并本流程产生的同问题素材。旧 `inbox_subjects`、已手工编辑的知识文章尚未自动映射到新组；本轮没有实现历史专题自动续写，不会改动现有文章。

## 网站端配置

同步默认关闭。服务器缺少账号、加密令牌文件或任一费用上限时不请求 X。

| 配置项 | 用途 |
| --- | --- |
| `OMNIHUB_X_BOOKMARK_SYNC` | 只有 `true` 才启用轮询 |
| `OMNIHUB_X_BOOKMARK_CLIENT_ID` | X 应用的 OAuth 客户端 ID |
| `OMNIHUB_X_BOOKMARK_CLIENT_SECRET` | 仅机密客户端需要，保留在服务器环境中 |
| `OMNIHUB_X_BOOKMARK_X_USER_ID` | 授权核验得到的 X 用户 ID |
| `OMNIHUB_X_BOOKMARK_TOKEN_FILE` | 仓库外、绝对路径的加密令牌文件 |
| `OMNIHUB_X_BOOKMARK_TOKEN_KEY` | 独立随机生成的 32 字节十六进制密钥，不进数据库或 Git |
| `OMNIHUB_X_BOOKMARK_RUN_USD` | 单轮预估费用上限，必须明确填写正数 |
| `OMNIHUB_X_BOOKMARK_DAY_USD` | 滚动 24 小时预估费用上限 |
| `OMNIHUB_X_BOOKMARK_MONTH_USD` | 滚动 31 天预估费用上限 |
| `OMNIHUB_X_BOOKMARK_MAX_PAGES` | 单轮分页保护，默认 20 页 |

当前按每页最多 100 条、每条 0.015 美元保守预留，满页需要先有 1.5 美元剩余预算。这个数是代码的风险上界假设，不是账户实际报价；上线时仍需核对 X 价格、账号优惠和供应商账单上限。超时等无法确认的请求保留预留，不能把失败请求当作免费。持续扫描大量历史收藏可能很贵，应先用小范围真实数据确认费用和分页行为，再决定上限。

服务器每分钟检查一次数据库里的到期时间；正常成功后两小时才会再次抓取。重启保留到期时间和未完成的分页游标。预算不足或分页保护触发后至少两小时再检查，不因达到费用上限反而加快读取。分钟检查不会每分钟调用 X。

## X 授权连接

使用官方 OAuth 2.0 Authorization Code with PKCE，并申请 `tweet.read users.read bookmark.read offline.access`。访问令牌过期时使用刷新令牌换新，轮换后的令牌立即写回加密文件。撤销授权、刷新失效或账号不符时需要重新连接，缩短轮询间隔不能延长失效的授权。

`scripts/connect-x-bookmarks.mjs` 负责生成连接地址和兑换授权。客户端 ID、已登记的精确回调地址、令牌文件和 PKCE 状态文件通过参数指定。回调 URL 含短期敏感字段，兑换时从标准输入读取，不放进命令行或聊天。兑换前核验 `state`、回调地址与有效期，并阻止重复使用。

核对授权账号的 `/users/me` 请求也可能计费，兑换必须另外配置 `OMNIHUB_X_BOOKMARK_CONNECT_USD`。授权需要用户在 X 页面亲自完成。本轮没有替用户注册应用、授权、转移令牌或读取个人收藏。

## 电脑与网站配对

只有 zane 的网站会话可以管理以下接口。写请求沿用站内来源检查。

| 接口 | 作用 |
| --- | --- |
| `GET /api/local-curation/settings` | 查看整理状态和 X 同步状态 |
| `POST /api/local-curation/settings` | 设置明确模型 ID，以及启用或暂停本地整理 |
| `POST /api/local-curation/devices` | 发放一次性展示的设备令牌，有效期 90 天 |
| `POST /api/local-curation/devices/{id}/revoke` | 撤销设备及其在途租约 |

设备令牌只允许访问专用的状态、领取、心跳、完成和失败接口，不能修改网站其他数据。服务器只保存令牌哈希。Codex 登录资料留在电脑，不传到网站。

本地配置放在仓库外，文件权限设为 0600。字段包括 `baseUrl`、`deviceToken`、明确的 `model` 和可选的绝对 `codexPath`、`outboxPath`。不在文档中提供真实令牌，模型 ID 也不能凭界面显示名猜测。当前没有新增配对设置页面，这些接口先用于受控接入。

脚本入口如下，路径需要替换为实际私有配置路径。

```sh
node scripts/run-local-curation.mjs --config /absolute/private-config.json --check
node scripts/run-local-curation.mjs --config /absolute/private-config.json --max-tasks 10
node scripts/install-local-curation-agent.mjs --config /absolute/private-config.json --out /absolute/local-curation.plist
```

生成器写出每 7200 秒运行一次的 macOS LaunchAgent。默认只生成文件；显式 `--install` 才复制到用户 LaunchAgents 目录。安装时不立即启动，但下次登录可能由 launchd 自动加载并开始定时执行，因此安装也需要完成启用前验收。当前没有安装或加载该任务。电脑休眠、关机或未登录时不能保证执行。

## 本地模型还缺什么

本机 Codex CLI 0.134.0 提供非交互执行、JSON Schema 输出和只读沙箱，但本轮没有验证出适合不可信 X 原文的全工具隔离方式。只读沙箱仍可能允许读取，不能直接当作纯文本模型调用。当前脚本明确返回 `tool_isolation_unavailable`，不会领取任务后反复失败或改用其他 API。

下一步需要接入并验收受支持的隔离文本调用方式，再运行一条合成样本验证输出和幂等回传。也可以在用户选择后，改用电脑上已有的模型 HTTP API，仅发送本轮来源文本和结构化提示，不开放模型工具。该替代路径本轮尚未实现，未经用户选择不切换供应商。

## 启用前的验收

先确认本地模型通道、X 应用授权和费用上限，再备份数据库及部署代码。部署后检查关闭状态下没有外部请求，随后用少量真实收藏核对原文、图片字段、新增范围和最终中文结果。通过后再启用两侧定时任务。

暂停时关闭服务器 `OMNIHUB_X_BOOKMARK_SYNC`、停用本地任务并撤销设备令牌即可。既有原文和已完成结果仍保留；不要删除收藏数据作为回退。
